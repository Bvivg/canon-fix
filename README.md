# canon-fix

Починка МФУ **Canon i-SENSYS MF46x** (MF461dw / MF463dw / MF465dw, серии MF460 и MF460 II) по USB на Windows 10/11 силами Claude Code.

В репозитории две вещи:

| Что | Где | Зачем |
|---|---|---|
| **Скилл для Claude Code** `canon-mf460-fix` | [`skills/canon-mf460-fix/`](skills/canon-mf460-fix/) | Вход и ключевые правила ([`SKILL.md`](skills/canon-mf460-fix/SKILL.md)) + полная база ([`reference.md`](skills/canon-mf460-fix/reference.md)): алгоритм по фазам Ф0–Ф10, каталог проблем П1–П21, скрипты S1–S12 и журнал четырёх реальных выездов |
| **Запускалка** `CanonFix.exe` | [`launcher/`](launcher/), готовый exe — в [Releases → latest](../../releases/latest) | Один файл на флешку: на «голом» ПК ставит Claude Code и скилл, создаёт `C:\fix`, спрашивает, что не работает, и открывает Claude Code с нужным промптом |

Скилл задаёт жёсткий порядок работы: физика → драйверы → **канал сканера (П1)** → печать → сетевой мусор → программа сканирования → профилактика USB → проверка. Главные правила: работать **только по USB** и никогда не уходить в сеть (в офисе много одинаковых Canon, и пробная страница легко уезжает на чужой стол — П15); модель определять по PID, а не по наклейке; делать точку восстановления и бэкап реестра до первой правки; отключать вместо удаления; не переустанавливать то, что уже есть в DriverStore; считать задачу закрытой только по чек-листу — напечатанный лист подтверждён человеком, а файлы сканов со стекла и с податчика открыты и прочитаны.

Итог работы — отчёт `C:\fix\report_<ИМЯ_ПК>.md` и `.json`. Содержимое отсканированных документов в отчёт не попадает: только «читается / не читается», размер и разрешение.

## Как получить `CanonFix.exe`

Интернет на целевом ПК нужен в любом случае: Claude Code качается с серверов Anthropic и требует входа в аккаунт. Поэтому самый простой путь — скачать exe прямо на том ПК, который чините.

**Прямая ссылка, всегда на последнюю сборку:**

```
https://github.com/Bvivg/canon-fix/releases/download/latest/CanonFix.exe
```

Открыть её в браузере на целевом ПК — или скачать одной командой в PowerShell:

```powershell
curl.exe -L -o "$env:USERPROFILE\Downloads\CanonFix.exe" https://github.com/Bvivg/canon-fix/releases/download/latest/CanonFix.exe
```

Файл появится в «Загрузках». Затем — правый клик → **«Запуск от имени администратора»**.

Страница релиза со списком версий и примечаниями: [Releases → latest](../../releases/latest).

**Флешка** нужна, только если на ПК неудобно открывать браузер или скачивать файлы: тогда скачайте exe заранее на свой компьютер и принесите. Ничего распаковывать не надо — это один самодостаточный файл, ни .NET, ни Node, ни git на целевом ПК не требуются.

## Как пользоваться

1. Зайдите на ПК под **той учётной записью, которая будет печатать и сканировать**. Она же должна быть администратором: exe требует прав администратора, а Claude Code, скилл и настройки сканера ставятся в профиль пользователя.
2. Запустите `CanonFix.exe` от имени администратора, подтвердите запрос UAC. Если SmartScreen пишет «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае» (exe не подписан).
3. Программа по шагам:
   1. включает новую консоль Windows (`HKCU\Console\ForceV2 = 1`) — в старой не работает вставка кода при входе;
   2. проверяет Claude Code в `%USERPROFILE%\.local\bin\claude.exe`, при отсутствии ставит официальным установщиком (`irm https://claude.ai/install.ps1 | iex`). **Качается ~180 МБ без индикатора прогресса** — окно может выглядеть зависшим несколько минут;
   3. добавляет `%USERPROFILE%\.local\bin` в PATH пользователя;
   4. ставит скилл в `%USERPROFILE%\.claude\skills\canon-mf460-fix\` — сначала пробует скачать свежую версию из этого репозитория, без интернета берёт копию, зашитую в exe. Показывает, какая версия поставлена и откуда;
   5. создаёт `C:\fix` и `C:\fix\backup`;
   6. спрашивает, что не работает: `1` сканер, `2` печать, `3` ничего, `4` чистая установка (новый ПК), `5` другое (своими словами), `6` только диагностика без изменений;
   7. открывает Claude Code в **новом окне** консоли с рабочей папкой `C:\fix` и промптом вида «Используй скилл canon-mf460-fix. Сначала прочитай reference.md целиком. На этом ПК: … Начни с Ф0 и работай по базе до результата.» Окно наследует права администратора от запускалки — они нужны для драйверов, портов и реестра.
4. В окне Claude Code:
   - при первом запуске откроется браузер для входа в аккаунт (нужна подписка Pro/Max/Team или Console-аккаунт). Войдите и вернитесь в консоль;
   - если Claude попросит вставить код — скопируйте его в браузере и вставьте в консоль **правой кнопкой мыши** или `Ctrl+V`. Код может не отображаться — это нормально, после вставки нажмите `Enter`;
   - на вопрос про доверие к папке `C:\fix` — `Yes`;
   - дальше Claude прочитает базу и начнёт с диагностики. Сначала только смотрит; каждую команду, меняющую систему, он предложит подтвердить.
5. **Будьте рядом.** Claude сам не дотянется до железа: он попросит проверить кабель, положить лист на стекло или в податчик и подтвердить, что напечатанный лист нормальный, а не пустой. Без этого работа не считается законченной.
6. Когда всё закончится — отчёты `C:\fix\report_<ИМЯ_ПК>.md` и `.json`, резервные копии в `C:\fix\backup\`, журнал самой запускалки — `C:\fix\launcher.log`.
7. Если Claude нашёл новую проблему, он допишет её в базу и положит копию в `C:\fix\reference_updated.md`. Передайте её в этот репозиторий — файлом через веб-интерфейс GitHub или задачей `@claude` (см. ниже), — чтобы на следующий ПК поехала дополненная версия.

Запускалка **не хранит токены и не реализует авторизацию** — только штатный вход Claude Code.

Если что-то пошло не так, Claude Code можно запустить вручную: открыть `cmd` **от администратора** в `C:\fix` и выполнить `claude "Используй скилл canon-mf460-fix. На этом ПК: <что не работает>. Начни с Ф0 и работай по базе до результата."`.

## Поставить только скилл, без exe

Если Claude Code на ПК уже стоит и нужна только свежая база, exe не нужен — три файла кладутся прямо из репозитория. В PowerShell:

```powershell
$d = "$env:USERPROFILE\.claude\skills\canon-mf460-fix"; New-Item -ItemType Directory -Force $d | Out-Null
'SKILL.md','reference.md','VERSION' | ForEach-Object {
  curl.exe -L -o "$d\$_" "https://raw.githubusercontent.com/Bvivg/canon-fix/main/skills/canon-mf460-fix/$_" }
Get-Content "$d\VERSION"
```

Последняя строка покажет версию установленной базы. Дальше — `claude` из папки `C:\fix` и промпт как выше.

## Как собрать

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0). На целевых ПК ничего ставить не нужно — exe самодостаточный.

```bash
dotnet publish launcher/CanonFix.csproj -c Release -r win-x64 -o out
```

Результат — `out/CanonFix.exe` (один файл, ~35 МБ). Собирается и на macOS/Linux — манифест `requireAdministrator` встраивается кросс-платформенно.

Проверка сборки без запуска сценария (работает и не на Windows):

```bash
dotnet run --project launcher -- --selftest
```

Версию exe задаёт `-p:Version=…`; без него — `0.0.0-local`.

### CI

[`.github/workflows/build.yml`](.github/workflows/build.yml): на каждый push в `main` собирает exe на `windows-latest`, прогоняет `CanonFix.exe --selftest` и пересоздаёт релиз **`latest`** с вложением `CanonFix.exe`. Тег `latest` всегда указывает на последний коммит `main`, версия сборки — `1.0.<номер прогона>`.

## Работа через `@claude` на GitHub

В репозитории лежит [.github/workflows/claude.yml](.github/workflows/claude.yml): пишете в issue или в комментарии к PR задачу с упоминанием `@claude` — Claude запускается прямо в GitHub Actions, правит скилл или код и открывает pull request. После вливания в `main` срабатывает `build.yml`, и в [Releases → latest](../../releases/latest) уже лежит пересобранный exe. Свой компьютер для этого не нужен вообще.

Чтобы это заработало, нужно один раз сделать две вещи (только владелец репозитория):

1. **Установить приложение Claude** на репозиторий: https://github.com/apps/claude → Install → выбрать `Bvivg/canon-fix`.
2. **Положить токен в секреты.** Локально в терминале:

```bash
claude setup-token
```

Скопировать выданный токен и добавить его в репозиторий: **Settings → Secrets and variables → Actions → New repository secret**, имя — `CLAUDE_CODE_OAUTH_TOKEN`, значение — токен. Токен привязан к вашей подписке Claude; запуски идут по ней, а не по API-тарифу.

Проверка: создать issue с текстом вроде «@claude добавь в базу пункт про …» — в течение минуты Claude ответит комментарием в этой же issue.

Запускать Claude могут только пользователи с правом записи в репозиторий; боты игнорируются. Лимит на прогон — 40 шагов и 30 минут.

## Как обновить скилл

База пополняется на выездах: Claude дописывает новые проблемы (П22, П23, …), строку в журнал выездов раздела 12 и поднимает версию в шапке, а копию кладёт в `C:\fix\reference_updated.md`.

1. Копируете принесённый файл поверх `skills/canon-mf460-fix/reference.md` (или правите `SKILL.md`).
2. Меняете дату в `skills/canon-mf460-fix/VERSION` **и** в `metadata.version` во frontmatter `SKILL.md` (самопроверка требует, чтобы они совпадали).
3. Push в `main` → CI соберёт новый exe с обновлённой встроенной копией.

Уже записанные флешки обновлять не обязательно: при наличии интернета запускалка сама скачивает актуальный скилл из `main` при каждом запуске. Без интернета ставится копия из exe.

Чтобы поставить скилл вручную (без запускалки), скопируйте папку `skills/canon-mf460-fix/` в `%USERPROFILE%\.claude\skills\` (на macOS/Linux — `~/.claude/skills/`) и вызовите в Claude Code `/canon-mf460-fix`.

## Что чинит скилл

Коротко (полный разбор — в [`reference.md`](skills/canon-mf460-fix/reference.md)):

- **П1** — Windows отдала канал сканера драйверу `usbprint` (узел `PI_00` вместо `MI_00`). Была на всех ПК, лечится переэнумерацией узла без установки чего-либо. Ломает и программы Canon, и печать (П12).
- **П2** — активен пакет драйвера сканера не под PID аппарата.
- **П3** — очередь печати на Microsoft IPP Class Driver: печать не идёт или выходят пустые листы, хотя журнал считает задание успешным.
- **П4** — протухшие `Device Id`/`Device Path` USB-порта печати после переезда в другой разъём.
- **П5** — сломанный print processor `CnXP0PP.DLL` (`0x20`).
- **П6** — `MI_01` в Code 10 после ручных правок.
- **П7** — аппарат отвалился по USB/питанию (родитель в problem 10 без серийника) — чинит только человек.
- **П8** — сетевой сканер-призрак маскирует проблему («устройство занято»).
- **П9** — запускается программа сканирования от другой модели (`28B5` ↔ `28DC`).
- **П10** — USB-кабель воткнут в разъём LAN принтера — чинит только человек.
- **П11** — `PI_00` есть, но Windows сканирует через eSCL: П1 без симптома.
- **П12** — П1 лечит и печать.
- **П13** — после П1 в ScanGear остался профиль-пустышка.
- **П14** — следы другого аппарата Canon, мёртвая очередь по умолчанию.
- **П15** — печать настроена на чужой сетевой аппарат: лист ушёл на другой стол.
- **П16** — нет прав администратора.
- **П17** — скан через податчик (АПД) даёт пустой PDF.
- **П18** — WIA-скан по умолчанию маленький и в BMP.
- **П19** — поставлен пакет драйверов не той серии (II ↔ без II).
- **П20** — Canon-очередь на USB-порту чужого устройства, `PendingDeletion`.
- **П21** — аппарат не виден по USB: выключен, не загрузился, плохое гнездо.

## Структура

```
canon-fix/
├── skills/canon-mf460-fix/     скилл: SKILL.md, reference.md, VERSION
├── launcher/                   C# (.NET 8) — CanonFix.exe
│   ├── CanonFix.csproj         single-file self-contained win-x64, скилл как EmbeddedResource
│   ├── app.manifest            requireAdministrator, UTF-8, longPathAware
│   ├── Program.cs              точка входа, --selftest / --version
│   ├── Launcher.cs             шаги 1–7
│   ├── SkillInstaller.cs       скачать из репо или распаковать встроенную копию
│   ├── EmbeddedSkill.cs        доступ к зашитым файлам
│   ├── SelfTest.cs             проверка exe и скилла
│   └── Log.cs                  консоль + C:\fix\launcher.log
└── .github/workflows/
    ├── build.yml           push в main → сборка exe → Release latest
    └── claude.yml          @claude в issue/PR → Claude правит репозиторий
```

`.gitignore` не пускает в репозиторий отчёты с компьютеров (`report_*.md`, `report_*.json`, `backup/`, `*.reg`) и секреты.
